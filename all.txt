## Architecture

```
┌─────────────┐    ┌────────────────┐    ┌──────────────────┐    ┌──────────────┐
│             │    │                │    │                  │    │              │
│  HSL GTFS   │───▶│   GTFS-RT      │───▶│    Kafka         │───▶│   Cassandra  │
│  Realtime   │    │   Producer     │    │    (KRaft)       │    │   (4.1)      │
│  API        │    │                │    │                  │    │              │
└─────────────┘    └────────────────┘    ├──────────────────┤    └──────────────┘
                                          │                  │
                                          │   Kafka UI       │
                                          │   (localhost:8080)│
                                          └──────────────────┘
```

| Composant | Technologie | Role |
|---|---|---|
| **Source** | HSL GTFS-RT API | Donnees temps-reel des bus/tram/metro d'Helsinki |
| **Producer** | Python 3.11 + `gtfs-realtime-bindings` | Telecharge, parse et publie dans Kafka (polling 5s) |
| **Transport** | Kafka 7.6.1 (KRaft, sans Zookeeper) | File de messages avec 3 topics |
| **Consumer** | Python 3.11 + `cassandra-driver` | Lit Kafka et ecrit dans Cassandra (batch UNLOGGED) |
| **Stockage** | Cassandra 4.1 | Base NoSQL columnar |
| **UI Kafka** | Kafka UI | Monitoring visuel des topics et messages |

## Requetes Trino validees pour Metabase

Connecte-toi a Metabase (`http://localhost:3000`) avec le driver **Presto**, hote `trino`, port `8080`, catalogue `cassandra`, schema `gtfs`.

### 1 — Retard moyen global

```sql
SELECT
    ROUND(CAST(AVG(avg_delay_seconds) AS double) / 60.0, 2) AS retard_moyen_min
FROM trip_updates
```

### 2 — Stats globales (trajets + lignes)

```sql
SELECT
    COUNT(*) AS total_trajets,
    COUNT(DISTINCT route_id) AS lignes_actives
FROM trip_updates
```

### 3 — Top 10 retards par ligne

```sql
SELECT
    route_id,
    ROUND(CAST(AVG(avg_delay_seconds) AS double) / 60.0, 1) AS retard_min,
    COUNT(*) AS nb_trajets
FROM trip_updates
WHERE avg_delay_seconds > 0
GROUP BY route_id
HAVING COUNT(*) > 3
ORDER BY retard_min DESC
LIMIT 10
```

### 4 — Alertes recentes

```sql
SELECT
    ingestion_time,
    header,
    description
FROM service_alerts
ORDER BY ingestion_time DESC
LIMIT 20
```

### 5 — Nombre total d'alertes

```sql
SELECT COUNT(*) AS total_alerts FROM service_alerts
```

## Data Flow

```
HSL API                     Kafka Topics                  Cassandra
─────────                   ─────────────                 ─────────
                            ┌──────────────────┐
vehicle-positions ────────▶ │ gtfs.vehicle_    │ ──────▶ vehicle_positions
                            │ positions        │         (route_id, date,
                            └──────────────────┘          ingestion_time DESC)
                            ┌──────────────────┐
trip-updates ─────────────▶ │ gtfs.trip_       │ ──────▶ trip_updates
                            │ updates          │         (route_id, date,
                            └──────────────────┘          ingestion_time DESC)
                            ┌──────────────────┐
service-alerts ───────────▶ │ gtfs.service_    │ ──────▶ service_alerts
                            │ alerts           │         (ingestion_time)
                            └──────────────────┘
```

### Topics Kafka

| Topic | Cle | Format | Description |
|---|---|---|---|
| `gtfs.vehicle_positions` | `full_vehicle_id` | JSON | Positions GPS des vehicules |
| `gtfs.trip_updates` | `route_id` | JSON | Retards et mises a jour de trajets |
| `gtfs.service_alerts` | *aucune* | JSON | Alertes service (travaux, perturbations) |

### Tables Cassandra

| Table | Partition Key | Clustering | Description |
|---|---|---|---|
| `vehicle_positions` | `(route_id, start_date)` | `ingestion_time DESC, vehicle_id` | Positions GPS avec operateur et statut lisible |
| `trip_updates` | `(route_id, start_date)` | `ingestion_time DESC` | Retards moyens par trajet |
| `service_alerts` | `ingestion_time` | - | Alertes texte avec periode de validite |

## Specifications techniques

### Points cles implementes

| Aspect | Implementation |
|---|---|
| **Vehicle ID** | `operator_id` + `vehicle_id` extraits du format HSL `<op>/<id>` |
| **Statut vehicule** | Stocke en texte lisible (`IN_TRANSIT_TO`, `STOPPED_AT`...) au lieu de l'enum entier |
| **Incertitude** | Champ `max_uncertainty` dans les trip updates (qualite donnee) |
| **Polling** | 5 secondes (evite rate limiting HSL) |
| **Batching Cassandra** | `BatchType.UNLOGGED` par lots de 50, buffer max 500 |
| **Commit Kafka** | Manuel (`enable_auto_commit=False`) apres chaque message |
| **Backpressure** | Flush force si le buffer depasse `MAX_BUFFER` |
| **Graceful shutdown** | Handlers `SIGTERM`/`SIGINT` + flush final + close producer/consumer |
| **Topics** | 3 topics distincts : positions, mises a jour, alertes |

### Ameliorations possibles

- Ajout de Trino pour le requetage SQL interome
- Metabase ou Apache Superset pour les dashboards
- Alerting sur les retards anormaux
- Compression avancee Kafka (ZSTD)
- Replication Cassandra multi-DC

import time
import requests
from google.transit import gtfs_realtime_pb2

URL = "https://realtime.hsl.fi/realtime/vehicle-positions/v2/hsl"

def fetch():
    try:
        r = requests.get(URL, timeout=10)
        r.raise_for_status()

        feed = gtfs_realtime_pb2.FeedMessage()
        feed.ParseFromString(r.content)

        vehicles = 0
        for entity in feed.entity:
            if entity.HasField("vehicle"):
                vehicles += 1

        return len(r.content), vehicles

    except Exception as e:
        return 0, f"error: {e}"


def main():
    start = time.time()

    while time.time() - start < 20:
        size, vehicles = fetch()
        print(f"Feed size: {size} bytes | Vehicles: {vehicles}")
        time.sleep(1)

    print("\nScan finished.")


if __name__ == "__main__":
    main()

-- Keyspace
CREATE KEYSPACE IF NOT EXISTS gtfs
WITH replication = {'class': 'SimpleStrategy', 'replication_factor': 1};

USE gtfs;

-- Table : positions des véhicules
-- Partition par route_id + jour → requêtes par ligne / période
-- trip_id volontairement absent (non fiable selon doc HSL)
CREATE TABLE IF NOT EXISTS vehicle_positions (
    route_id        text,
    start_date      text,
    ingestion_time  bigint,
    operator_id     text,
    vehicle_id      text,
    full_vehicle_id text,
    direction_id    int,
    start_time      text,
    latitude        double,
    longitude       double,
    bearing         float,
    speed           float,
    current_status  text,
    gtfs_timestamp  bigint,
    PRIMARY KEY ((route_id, start_date), ingestion_time, vehicle_id)
) WITH CLUSTERING ORDER BY (ingestion_time DESC);

-- Table : retards par trajet
CREATE TABLE IF NOT EXISTS trip_updates (
    route_id            text,
    start_date          text,
    ingestion_time      bigint,
    start_time          text,
    direction_id        int,
    avg_delay_seconds   double,
    num_stops           int,
    gtfs_timestamp      bigint,
    PRIMARY KEY ((route_id, start_date), ingestion_time)
) WITH CLUSTERING ORDER BY (ingestion_time DESC);

-- Table : alertes service
CREATE TABLE IF NOT EXISTS service_alerts (
    ingestion_time bigint,
    header text,
    description text,
    start_time bigint,
    end_time bigint,
    PRIMARY KEY (ingestion_time)
);

        self.session  = None
        self.stmt_vp  = None
        self.stmt_tu  = None
        self.stmt_sa  = None
        self._connect()

    def _connect(self, retries: int = 20):
        for attempt in range(1, retries + 1):
            try:
                cluster = Cluster(
                    [config.CASSANDRA_HOST],
                    port=config.CASSANDRA_PORT,
                    reconnection_policy=ExponentialReconnectionPolicy(1, 60),
                )
                self.session = cluster.connect(config.CASSANDRA_KEYSPACE)
                self.stmt_vp = self.session.prepare(INSERT_VEHICLE)
                self.stmt_tu = self.session.prepare(INSERT_TRIP)
                self.stmt_sa = self.session.prepare(INSERT_ALERT)
                logger.info(f"Cassandra connected ({config.CASSANDRA_HOST})")
                return
            except Exception as e:
                logger.warning(f"Cassandra not ready ({attempt}/{retries}): {e}")
                time.sleep(5)
        raise RuntimeError("Cannot connect to Cassandra")

    def insert_vehicle_position(self, msg: dict):
        self.session.execute(self.stmt_vp, (
            msg["operator_id"],
            msg["vehicle_id"],
            msg["full_vehicle_id"],
            msg["route_id"],
            msg["direction_id"],
            msg["start_date"],
            msg["start_time"],
            msg["latitude"],
            msg["longitude"],
            msg["bearing"],
            msg["speed"],
            msg["current_status"],
            msg["gtfs_timestamp"],
            msg["ingestion_time"],
        ))

    def insert_trip_update(self, msg: dict):
        self.session.execute(self.stmt_tu, (
            msg["route_id"],
            msg["start_date"],
            msg["start_time"],
            msg["direction_id"],
            msg["avg_delay_seconds"],
            msg["num_stops"],
            msg["gtfs_timestamp"],
            msg["ingestion_time"],
        ))

    def insert_service_alert(self, msg: dict):
        self.session.execute(self.stmt_sa, (
            msg["ingestion_time"],
            msg["header"],
            msg["description"],
            msg["start_time"],
            msg["end_time"],
        ))

"""
Lit les messages Kafka et les persiste dans Cassandra.
"""
import json
import logging
import time
from kafka import KafkaConsumer
from kafka.errors import NoBrokersAvailable
import config
from cassandra_client import CassandraClient

logger = logging.getLogger(__name__)


def create_consumer(retries: int = 15) -> KafkaConsumer:
    for attempt in range(1, retries + 1):
        try:
            c = KafkaConsumer(
                config.TOPIC_VEHICLE_POSITIONS,
                config.TOPIC_TRIP_UPDATES,
                config.TOPIC_SERVICE_ALERTS,
                bootstrap_servers=config.KAFKA_BOOTSTRAP_SERVERS,
                group_id=config.KAFKA_GROUP_ID,
                auto_offset_reset="earliest",
                enable_auto_commit=False,
                value_deserializer=lambda v: json.loads(v.decode("utf-8")),
            )
            logger.info("✅ Kafka consumer ready")
            return c
        except NoBrokersAvailable:
            logger.warning(f"⏳ Kafka not ready ({attempt}/{retries}), waiting 5s...")
            time.sleep(5)
    raise RuntimeError("❌ Cannot connect to Kafka")


def run(consumer: KafkaConsumer, db: CassandraClient, is_running=None):
    logger.info("Listening to Kafka topics...")
    counts = {config.TOPIC_VEHICLE_POSITIONS: 0, config.TOPIC_TRIP_UPDATES: 0, config.TOPIC_SERVICE_ALERTS: 0}

    while True:
        records = consumer.poll(timeout_ms=1000)
        if not records:
            if is_running and not is_running():
                break
            continue

        for topic_partition, messages in records.items():
            for record in messages:
                topic = record.topic
                msg   = record.value

                try:
                    if topic == config.TOPIC_VEHICLE_POSITIONS:
                        db.insert_vehicle_position(msg)
                    elif topic == config.TOPIC_TRIP_UPDATES:
                        db.insert_trip_update(msg)
                    elif topic == config.TOPIC_SERVICE_ALERTS:
                        db.insert_service_alert(msg)

                    consumer.commit()
                    counts[topic] += 1

                    if sum(counts.values()) % 500 == 0:
                        logger.info(f"  Inserted: VP={counts[config.TOPIC_VEHICLE_POSITIONS]} | TU={counts[config.TOPIC_TRIP_UPDATES]} | SA={counts[config.TOPIC_SERVICE_ALERTS]}")

                except Exception as e:
                    logger.error(f"Error processing [{topic}]: {e} | msg={msg}")

from consumer import create_consumer, run

    global running
    logger.info("Shutdown signal received, exiting...")
    running = False

    signal.signal(signal.SIGTERM, shutdown)
    signal.signal(signal.SIGINT, shutdown)

"""
Backend FastAPI — expose les données GTFS via REST et WebSocket.
Interroge Trino, qui lit Cassandra via son connecteur officiel.
"""
from fastapi import FastAPI, WebSocket, WebSocketDisconnect
from fastapi.templating import Jinja2Templates
from fastapi.requests import Request
import trino
import asyncio
from datetime import date

app = FastAPI(title="GTFS-RT Dashboard")
templates = Jinja2Templates(directory="templates")


def get_trino_cursor():
    conn = trino.dbapi.connect(
        host="trino",
        port=8080,
        user="dashboard",
        catalog="cassandra",
        schema="gtfs",
    )
    return conn.cursor()


def query(sql: str) -> list[dict]:
    cur = get_trino_cursor()
    cur.execute(sql)
    cols = [d[0] for d in cur.description]
    return [dict(zip(cols, row)) for row in cur.fetchall()]


def today() -> str:
    return date.today().strftime("%Y%m%d")


# ── Vehicle Positions ─────────────────────────────────────────────────────────

def fetch_live_positions() -> list[dict]:
    """Derniere position GPS de chaque vehicule (60 dernieres secondes)."""
    return query("""
        WITH ranked AS (
            SELECT
                vehicle_id, route_id,
                latitude, longitude,
                ROUND(CAST(speed AS double) * 3.6, 1) AS vitesse_kmh,
                bearing, current_status,
                ROW_NUMBER() OVER (
                    PARTITION BY vehicle_id
                    ORDER BY ingestion_time DESC
                ) AS rn
            FROM vehicle_positions
            WHERE ingestion_time > (to_unixtime(now()) - 60)
        )
        SELECT vehicle_id, route_id, latitude, longitude,
               vitesse_kmh, bearing, current_status
        FROM ranked
        WHERE rn = 1
          AND latitude  BETWEEN 59.9 AND 60.5
          AND longitude BETWEEN 24.5 AND 25.5
    """)


def fetch_vehicle_stats() -> dict:
    """Stats vehicules (compte, vitesse moyenne)."""
    rows = query("""
        SELECT
            COUNT(DISTINCT vehicle_id) AS vehicules_actifs,
            ROUND(CAST(AVG(speed) AS double) * 3.6, 1) AS vitesse_moy_kmh
        FROM vehicle_positions
        WHERE ingestion_time > (to_unixtime(now()) - 60)
    """)
    return rows[0] if rows else {"vehicules_actifs": 0, "vitesse_moy_kmh": 0.0}


# ── Trip Updates ──────────────────────────────────────────────────────────────

def fetch_top_delays() -> list[dict]:
    """Top 10 lignes les plus en retard — scan complet, filtré côté Trino."""
    return query("""
        SELECT
            route_id,
            ROUND(CAST(AVG(avg_delay_seconds) AS double) / 60.0, 1) AS retard_min,
            COUNT(*) AS nb_trajets
        FROM trip_updates
        WHERE avg_delay_seconds > 0
        GROUP BY route_id
        HAVING COUNT(*) > 3
        ORDER BY retard_min DESC
        LIMIT 10
    """)


def fetch_global_stats_updates() -> dict:
    """Statistiques globales sur les trip updates."""
    rows = query("""
        SELECT
            COUNT(*)  AS total_trajets,
            COUNT(DISTINCT route_id) AS lignes_actives,
            ROUND(CAST(AVG(avg_delay_seconds) AS double) / 60.0, 2) AS retard_moyen_min
        FROM trip_updates
    """)
    return rows[0] if rows else {"total_trajets": 0, "lignes_actives": 0, "retard_moyen_min": 0.0}


# ── Service Alerts ────────────────────────────────────────────────────────────

def fetch_recent_alerts() -> list[dict]:
    """20 dernières alertes."""
    return query("""
        SELECT
            ingestion_time,
            header,
            description,
            start_time,
            end_time
        FROM service_alerts
        ORDER BY ingestion_time DESC
        LIMIT 20
    """)


def fetch_alert_count() -> dict:
    """Nombre total d'alertes."""
    rows = query("SELECT COUNT(*) AS total_alerts FROM service_alerts")
    return rows[0] if rows else {"total_alerts": 0}

  return L.divIcon({

    html: `<div style="
      width:0;height:0;
      border-left:6px solid transparent;

function onVehicleClick(vehicleId) {
  if (selectedVehicle === vehicleId) {
    map.removeLayer(trajectoryLine);
    trajectoryLine = null;
    selectedVehicle = null;
    return;
  }
  if (trajectoryLine) {
    map.removeLayer(trajectoryLine);
    trajectoryLine = null;
  }
  selectedVehicle = vehicleId;

  fetch(`/api/trajectory/${vehicleId}`)
    .then(r => r.json())
    .then(points => {
      if (!points.length) return;
      const latlngs = points.map(p => [p.latitude, p.longitude]);
      trajectoryLine = L.polyline(latlngs, {
        color: '#ffaa44',
        weight: 3,
        opacity: 0.7,
      }).addTo(map);
      map.fitBounds(trajectoryLine.getBounds().pad(0.05));
    });
}

function updateMarkers(positions) {
  const seen = new Set();

  positions.forEach(v => {
    seen.add(v.vehicle_id);
    const lat = v.latitude;
    const lng = v.longitude;
    const bearing = v.bearing || 0;
    const color = speedColor(v.vitesse_kmh || 0);

    if (markers[v.vehicle_id]) {
      markers[v.vehicle_id].setLatLng([lat, lng]);
      markers[v.vehicle_id].setIcon(arrowIcon(bearing, color));
    } else {
      const marker = L.marker([lat, lng], {
        icon: arrowIcon(bearing, color),
        zIndexOffset: 1000,
      }).addTo(map);

      marker.bindPopup(`
        <b>Ligne ${v.route_id}</b><br>
        Véhicule : ${v.vehicle_id}<br>
        Vitesse : ${v.vitesse_kmh} km/h<br>
        Statut : ${v.current_status}
      `);

      marker.on('click', () => onVehicleClick(v.vehicle_id));
      markers[v.vehicle_id] = marker;
    }
  });

  Object.keys(markers).forEach(id => {
    if (!seen.has(id)) {
      map.removeLayer(markers[id]);
      delete markers[id];
    }
  });
}

"""
Télécharge et parse les flux GTFS-RT HSL.
Retourne des dicts Python prêts à sérialiser en JSON.
"""
import time
import logging
import requests
from google.transit import gtfs_realtime_pb2
import config

logger = logging.getLogger(__name__)


def _download(url: str) -> bytes | None:
    try:
        r = requests.get(
            url,
            headers={"User-Agent": config.USER_AGENT},
            timeout=30
        )
        r.raise_for_status()
        return r.content
    except Exception as e:
        logger.error(f"Download failed [{url}]: {e}")
        return None


def fetch_vehicle_positions() -> list[dict]:
    raw = _download(config.GTFS_VEHICLE_URL)
    if not raw:
        return []

    feed = gtfs_realtime_pb2.FeedMessage()
    feed.ParseFromString(raw)

    now = int(time.time())
    results = []

    STATUS_MAP = {
        0: "INCOMING_AT",
        1: "STOPPED_AT",
        2: "IN_TRANSIT_TO",
    }

    if not feed.entity:
        logger.info("  vehicle_positions : feed empty (no active vehicles)")
        return []

    for entity in feed.entity:
        v = entity.vehicle
        if not v.vehicle.id:
            continue

        full_id = v.vehicle.id
        parts = full_id.split("/", 1)
        operator_id = parts[0] if len(parts) > 1 else ""
        vehicle_id  = parts[1] if len(parts) > 1 else parts[0]

        results.append({
            "operator_id":     operator_id,
            "vehicle_id":      vehicle_id,
            "full_vehicle_id": full_id,
            "route_id":        v.trip.route_id if v.HasField("trip") else "",
            "direction_id":    v.trip.direction_id if v.HasField("trip") else 0,
            "start_date":      v.trip.start_date   if v.HasField("trip") else "",
            "start_time":      v.trip.start_time   if v.HasField("trip") else "",
            "latitude":        v.position.latitude,
            "longitude":       v.position.longitude,
            "bearing":         v.position.bearing,
            "speed":           v.position.speed,
            "current_status":  STATUS_MAP.get(v.current_status, "UNKNOWN"),
            "gtfs_timestamp":  v.timestamp,
            "ingestion_time":  now,
        })

    return results


def fetch_trip_updates() -> list[dict]:
    raw = _download(config.GTFS_TRIP_URL)
    if not raw:
        return []

    feed = gtfs_realtime_pb2.FeedMessage()
    feed.ParseFromString(raw)

    now = int(time.time())
    results = []

    for entity in feed.entity:
        if not entity.HasField("trip_update"):
            continue
        tu   = entity.trip_update
        trip = tu.trip

        delays = []
        uncertainties = []
        for stu in tu.stop_time_update:
            if stu.HasField("arrival"):
                delays.append(stu.arrival.delay)
                if stu.arrival.uncertainty:
                    uncertainties.append(stu.arrival.uncertainty)
            if stu.HasField("departure"):
                delays.append(stu.departure.delay)
                if stu.departure.uncertainty:
                    uncertainties.append(stu.departure.uncertainty)

        results.append({
            "route_id":            trip.route_id      if trip.route_id    else "",
            "start_date":          trip.start_date    if trip.start_date  else "",
            "start_time":          trip.start_time    if trip.start_time  else "",
            "direction_id":        trip.direction_id,
            "avg_delay_seconds":   sum(delays) / len(delays) if delays else 0.0,
            "max_uncertainty":     max(uncertainties) if uncertainties else 0,
            "num_stops":           len(tu.stop_time_update),
            "gtfs_timestamp":      now,
            "ingestion_time":      now,
        })

    return results


def fetch_service_alerts() -> list[dict]:
    raw = _download(config.GTFS_ALERTS_URL)
    if not raw:
        return []

    feed = gtfs_realtime_pb2.FeedMessage()
    feed.ParseFromString(raw)

    now = int(time.time())
    results = []

    for entity in feed.entity:
        if not entity.HasField("alert"):
            continue

        a = entity.alert

        results.append({
            "header": a.header_text.translation[0].text if a.header_text.translation else "",
            "description": a.description_text.translation[0].text if a.description_text.translation else "",
            "start_time": a.active_period[0].start if a.active_period else None,
            "end_time": a.active_period[0].end if a.active_period else None,
            "ingestion_time": now
        })

    return results

"""
Boucle principale : fetch → parse → publish → sleep.
"""
import logging
import signal
import time
import config
from fetcher import fetch_vehicle_positions, fetch_trip_updates, fetch_service_alerts
from producer import create_producer, publish

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [PRODUCER] %(levelname)s %(message)s",
    datefmt="%H:%M:%S",
)
logger = logging.getLogger(__name__)

running = True


def shutdown(signum, frame):
    global running
    logger.info("Shutdown signal received, exiting...")
    running = False


def main():
    global running
    signal.signal(signal.SIGTERM, shutdown)
    signal.signal(signal.SIGINT, shutdown)

    logger.info("GTFS Producer starting...")
    producer = create_producer()

    iteration = 0
    while running:
        iteration += 1
        logger.info(f"-- Iteration #{iteration} ---------------------")

        vp = fetch_vehicle_positions()
        if vp:
            n = publish(producer, config.TOPIC_VEHICLE_POSITIONS, vp, "full_vehicle_id")
            logger.info(f"  vehicle_positions : {n}/{len(vp)} sent")
        else:
            logger.info("  vehicle_positions : 0/0 sent")

        tu = fetch_trip_updates()
        if tu:
            n = publish(producer, config.TOPIC_TRIP_UPDATES, tu, "route_id")
            logger.info(f"  trip_updates      : {n}/{len(tu)} sent")

        sa = fetch_service_alerts()
        if sa:
            n = publish(producer, config.TOPIC_SERVICE_ALERTS, sa, None)
            logger.info(f"  service_alerts    : {n}/{len(sa)} sent")

        if running:
            logger.info(f"  sleeping {config.POLL_INTERVAL_SECONDS}s...")
            time.sleep(config.POLL_INTERVAL_SECONDS)

    producer.close()
    logger.info("Producer stopped.")


if __name__ == "__main__":
    main()

"""
Publie les messages dans les topics Kafka.
"""
import json
import logging
import time
from kafka import KafkaProducer
from kafka.errors import NoBrokersAvailable
import config

logger = logging.getLogger(__name__)


def create_producer(retries: int = 15) -> KafkaProducer:
    for attempt in range(1, retries + 1):
        try:
            p = KafkaProducer(
                bootstrap_servers=config.KAFKA_BOOTSTRAP_SERVERS,
                value_serializer=lambda v: json.dumps(v).encode("utf-8"),
                key_serializer=lambda k: str(k).encode("utf-8") if k else None,
                acks="all",
                retries=3,
                compression_type="gzip",
            )
            logger.info(f"✅ Kafka connected: {config.KAFKA_BOOTSTRAP_SERVERS}")
            return p
        except NoBrokersAvailable:
            logger.warning(f"⏳ Kafka not ready ({attempt}/{retries}), waiting 5s...")
            time.sleep(5)
    raise RuntimeError("❌ Cannot connect to Kafka after retries")


def publish(producer: KafkaProducer, topic: str, messages: list[dict], key_field: str | None = None) -> int:
    sent = 0
    for msg in messages:
        key = msg.get(key_field) if key_field else None
        try:
            producer.send(topic, key=key, value=msg).get(timeout=10)
            sent += 1
        except Exception as e:
            logger.error(f"Send error on {topic}: {e}")
    return sent
